# Wedding exports checklist

Every wedding with a blog post on the website, newest post first. Tick each one off once its
Lightroom export is done.

- **Post date** is when the blog post went up, not the wedding date. It's there to help you find the
  right catalogue.
- **Photos on site** is how many photos the post shows now.
- **Export settings:** 2048px long edge. Export black and white versions into a `mono` subfolder,
  e.g. `web\2026-tay-and-jesse\colour\mono`.

## Exporting only the photos on the site

Under each wedding is the list of camera file names for the photos its blog post uses.

1. Open the wedding's catalogue, go to the Library, and select the shoot's folder or All Photographs.
2. Show the Library Filter bar (press `\`), then choose **Text > Filename > Contains**.
3. Copy the wedding's list and paste it into the search box. Only those photos stay visible.
4. A file name also matches its edits and virtual copies (`-Edit`, `-2` and so on). Where more than
   one version shows, export the ones with your green (colour) or purple (mono) label.
5. Select them all and export.

If the count looks short, a photo may have been renamed in Lightroom. Export what you find; the
matching script will list anything still missing.
